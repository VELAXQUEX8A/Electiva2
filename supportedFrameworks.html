📌 Vercel

¿Qué es Vercel?

Vercel es una plataforma en la nube que facilita el despliegue de aplicaciones frontend, full-stack y backend modernas. Se integra con repositorios Git como GitHub o GitLab y genera automáticamente previews de cada Pull Request.

Sus principales características incluyen:

  • Funciones serverless y ejecución en el borde (Edge Functions).
  • Optimización de imágenes y contenido.
  • Entrega de contenido mediante una CDN global.
  • Soporte para renderizado en servidor (SSR) y regeneración estática incremental (ISR).

Frameworks Soportados

Vercel ofrece soporte nativo y optimizado para múltiples frameworks populares. Entre ellos destacan:

  • Next.js (soporte completo, framework oficial de Vercel).
  • SvelteKit
  • Nuxt (Vue.js)
  • Astro
  • Remix
  • Vite
  • Gatsby
  • Create React App (CRA)

Cada framework tiene diferentes niveles de compatibilidad con funciones como:

  • Routing y middleware en el borde.
  • Renderizado en servidor (SSR) y Streaming SSR.
  • Regeneración Estática Incremental (ISR).
  • Optimización y generación dinámica de imágenes (incluyendo OG images).
