Getting Started con Vercel

1. Crear una cuenta

Regístrate gratis usando GitHub, GitLab o Bitbucket. Al hacerlo, podrás conectar tus repositorios directamente para desplegar aplicaciones.

2. Importar un proyecto

Vercel detecta automáticamente el framework de tu proyecto (ejemplo: Next.js, React, Vue, Angular, Astro, etc.). Si no lo reconoce, puedes configurarlo manualmente indicando el comando de build y la carpeta de salida.

3. Desplegar tu aplicación

  • Con un clic, tu proyecto se despliega en la nube.
  • Cada rama o commit genera una URL de previsualización.
  • Al fusionar cambios en la rama principal, se crea una versión en producción con URL estable.

4. Opciones avanzadas

  • Vercel CLI: despliega desde la terminal con npm i -g vercel.
  • vercel.json: permite configurar detalles del proyecto.
  • Colaboración: invita a tu equipo para trabajar juntos en un mismo proyecto.

En resumen, Vercel facilita pasar de tu código a una aplicación en la nube lista para producción, en minutos y sin configuraciones complicadas.
